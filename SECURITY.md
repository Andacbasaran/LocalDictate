# Security & Privacy Policy

## Privacy-First Architecture

**LocalDictate** is designed from the ground up as an **air-gapped, zero-telemetry desktop voice studio**:

- **100% Local Speech-to-Text**: All microphone audio is captured in memory and transcribed locally via `faster-whisper` (CTranslate2 INT8 on CPU). Audio buffers are never uploaded to any third-party cloud server.
- **Air-Gapped Offline Lock (`offline_only=True` by default)**: Blocks any non-localhost LLM endpoints and disables automatic GitHub update checks until the user explicitly opts out.
- **Local Encrypted-at-Rest OS Storage**: Configuration (`config.json`) and dictation history (`history.db`) live exclusively in your OS user profile (`%APPDATA%\LocalDictate`, `~/Library/Application Support/LocalDictate`, or `$XDG_DATA_HOME/localdictate`).
- **Clipboard Preservation**: Dictated text is placed on the clipboard briefly to execute OS paste and automatically restored after `450 ms` only when paste succeeds.

## Verifying Release Binaries

Every official GitHub Release ships with a unified `SHA256SUMS.txt` generated by GitHub Actions directly from source.

```bash
# Windows (PowerShell)
Get-FileHash LocalDictate-Setup-v1.0.0-Windows-x64.exe -Algorithm SHA256

# macOS
shasum -a 256 LocalDictate-v1.0.0-macOS-arm64.dmg

# Linux
sha256sum -c --ignore-missing SHA256SUMS.txt
```

## Reporting a Vulnerability

If you discover a security issue (such as unsafe subprocess invocation, privilege escalation, clipboard leakage, or supply-chain concerns):

1. **Do not** open a public issue with exploit details.
2. Report privately via [GitHub Security Advisories](https://github.com/Andacbasaran/LocalDictate/security/advisories/new).
3. Include reproduction steps, affected OS/version, and suggested mitigation if available.

We aim to acknowledge reports within **48 hours** and release fixes promptly.
